# loro FSP-Simulationsbogen – Updates

Dieses Repository enthält nur die veröffentlichten Versionen der Desktop-App
„FSP-Simulation“ der Sprachschule loro. Der Quellcode liegt nicht hier.

Die App sucht hier über den Knopf **„Nach Updates suchen“** nach neuen Versionen.
Jede Version ist mit einem eigenen Schlüssel signiert; die App installiert nur
Pakete, deren Signatur gültig ist.

Es gibt hier nichts herunterzuladen oder auszuführen.
